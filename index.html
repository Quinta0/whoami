01 · Chip scale · open source

No documentation? Read the wire.

A vendor shipped a USB device with an undocumented protocol. I captured its raw HID reports in Wireshark, decoded the byte layout for DPI profiles, polling rates and on-board memory, and wrote a complete Linux driver in C. It was merged upstream.

  • libratbag PR #1873, mergedA USB HID device driver written from a packet capture.
  • ProtonPlus PR #1260, merged for v0.6.9Diagnostics that detect broken Steam compatibility tools and guide recovery, after tracing Steam Linux Runtime crash loops in Valve's tracker (#13248).
  • DLSS-Updater PRs #283, #252, #256Bounded manifest parsing so DLSS, FSR and XeSS libraries survive DLL upgrades.
